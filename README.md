# Móveis Sob Medida

Landing page de vendas para projetos de móveis sob medida.

## Como ativar o site (GitHub Pages)

1. Vá em **Settings** → **Pages**
2. Em **Source**, selecione a branch `main` e pasta `/ (root)`
3. Clique em **Save**
4. Em alguns minutos o site estará no ar em:  
   `https://andermuchael-glitch.github.io/moveis-sob-medida/`

## Importante

- Faça upload do arquivo `hero-kitchen.jpg` na raiz do repositório (mesmo lugar do index.html) para a imagem da cozinha aparecer.
- Altere o número do WhatsApp no arquivo `index.html` (procure por `WHATSAPP_NUMBER`).
